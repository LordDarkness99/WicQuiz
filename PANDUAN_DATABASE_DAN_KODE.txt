BAGIAN 2: RLS (Row Level Security) YANG HARUS AKTIF
================================================================================

JANGAN UBAH RLS POLICIES BERIKUT:

qt_rooms:          RLS ON  — Anyone can read/create/update (permissive)
qt_quizzes:        RLS ON  — Anyone can read/create (permissive)
qt_questions:      RLS ON  — Anyone can read/create (permissive)
qt_players:        RLS ON  — Anyone can read/create/update (permissive)
qt_answers:        RLS ON  — Anyone can read/create/update (permissive)
qt_question_bank:  RLS ON  — INSERT/UPDATE: WITH CHECK (true)
qt_quiz_templates: RLS ON  — INSERT/UPDATE: WITH CHECK (true)
qt_session_results:RLS OFF — Disabled (agar bisa insert tanpa auth session)
profiles:          RLS ON  — Public read, user can insert/update own
user_quiz_logs:    RLS OFF — Disabled (agar tidak blokir insert)

PENTING: Jika RLS diubah ke strict (misalnya owner_id = auth.uid()),
         maka semua INSERT akan GAGAL dan quiz tidak bisa disimpan!

di Supabase Dashboard → SQL Editor:

------- MULAI SQL -------

-- Fix 1: Tambah owner_id ke session_results (jika belum ada)
ALTER TABLE qt_session_results
  ADD COLUMN IF NOT EXISTS owner_id UUID REFERENCES auth.users(id) ON DELETE CASCADE;
ALTER TABLE qt_session_results DISABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "Users read own session results" ON qt_session_results;
DROP POLICY IF EXISTS "Users insert own session results" ON qt_session_results;

-- Fix 2: Disable RLS user_quiz_logs
DROP POLICY IF EXISTS "Users can read own quiz logs" ON user_quiz_logs;
DROP POLICY IF EXISTS "Users can insert own quiz logs" ON user_quiz_logs;
ALTER TABLE user_quiz_logs DISABLE ROW LEVEL SECURITY;

-- Fix 3: Permissive policies templates & question bank
DROP POLICY IF EXISTS "Users insert own quiz templates" ON qt_quiz_templates;
DROP POLICY IF EXISTS "Users update own quiz templates" ON qt_quiz_templates;
CREATE POLICY "Users insert own quiz templates" ON qt_quiz_templates FOR INSERT WITH CHECK (true);
CREATE POLICY "Users update own quiz templates" ON qt_quiz_templates FOR UPDATE USING (true) WITH CHECK (true);

DROP POLICY IF EXISTS "Users insert own question bank" ON qt_question_bank;
DROP POLICY IF EXISTS "Users update own question bank" ON qt_question_bank;
CREATE POLICY "Users insert own question bank" ON qt_question_bank FOR INSERT WITH CHECK (true);
CREATE POLICY "Users update own question bank" ON qt_question_bank FOR UPDATE USING (true) WITH CHECK (true);
